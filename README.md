# ValeFit

ValeFit is a modern fitness and wellness web application focused on helping users build healthier lifestyles through expert-guided workouts, smart nutrition tips, and flexible membership plans.

The platform is designed to be clean, responsive, and easy to use across all devices.

---

## ✨ Features
- Responsive landing pages with modern UI
- Membership plans with clear pricing and features
- Health & nutrition blog with images
- Active navigation highlighting
- Clean, reusable component structure
- Mobile-friendly layouts
- Scalable design for future features

---

## 🛠 Tech Stack

- React – UI development
- React Router – Client-side routing
- Tailwind CSS – Styling and responsiveness
- React Icons – Consistent icon usage

## 🚀 Getting Started
1. Clone the repository

```bash
git clone https://github.com/stephany247/valefit.git
cd valefit
```

2. Install dependencies
```bash
npm install
```

3. Run the development server
```bash
npm run dev
```
The app will be available at http://localhost:5173 (or the port shown in your terminal).

## 🎨 Design Approach

- Mobile-first and fully responsive
- Minimal fixed sizing (uses flexible layouts)

- Clear visual hierarchy and spacing
